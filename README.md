# ⚡ Quiz Battle — Multiplayer Trivia Game

A fun, interactive quiz game where players answer trivia questions, earn points, and compete for the top spot on the leaderboard.

## 🚀 Features

- 🎮 Create a game room with a unique room code
- 👥 Support for 2–8 players in the planned multiplayer experience
- 🧠 Multiple-choice trivia questions across different categories
- ⏱️ 15-second timer for each question
- ⚡ Score points for correct answers with a speed bonus
- 🏆 Final scores and leaderboard
- 📱 Responsive design for desktop, tablet, and mobile
- 🤖 Demo players to explore the gameplay locally

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Clipboard API

## 🎯 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/amitv28242/quiz-battle.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

No build tools are required for the current frontend prototype.

## 🎮 How to Play

1. Enter your player name.
2. Create a room or select demo mode.
3. Add demo players if needed.
4. Answer each question before the timer runs out.
5. Earn points for correct answers and speed.
6. Check the final leaderboard to see who wins.

## ⚠️ Current Limitations

This project is currently a frontend prototype. Room codes and demo players work locally in the browser; real-time multiplayer across different devices requires a backend server and a shared room-management system.
